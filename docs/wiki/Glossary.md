# PC-Free — Glossary

- **Codespaces:** GitHub-hosted development environment.
- **Docker Compose:** YAML-based multi-container configuration used in the README example.
- **dockurr/windows:** Third-party container image named in the README.
- **noVNC:** Browser-based remote desktop access referenced by the README.
- **RDP:** Remote Desktop Protocol; optional port 3389 mapping in the example.
- **Docker volume:** Persistent storage object; deleting it with `down -v` removes its data.
